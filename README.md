# Razer Mouse Battery

Маленькая программа для Windows, которая показывает заряд мышки Razer **без Razer Synapse**.

- батарейка с заливкой: зелёная от 60%, оранжевая от 25%, красная ниже
- оценка оставшегося времени (сначала по паспорту, потом по вашему реальному расходу)
- при зарядке — белая заливка и молния
- живёт в трее, как Discord: крестик сворачивает, повторный запуск разворачивает окно
- мгновенно замечает подключение/отключение провода
- в простое не нагружает процессор: мышь опрашивается раз в минуту

Проверено на **Razer DeathAdder V3 HyperSpeed** (донгл `1532:00C5`, провод `1532:00C4`).
Другие беспроводные мыши Razer, скорее всего, тоже заработают — добавьте их PID в `PIDS` в `main.pyw`.

## Запуск

Скачайте `MouseBattery.exe` из [Releases](../../releases) и запустите. Synapse при этом лучше закрыть.

## Сборка из исходников

Нужен Python 3.10+ (с python.org, галка «Add to PATH»).

```
build.bat
```

Скрипт поставит зависимости, нарисует иконку и соберёт `MouseBattery.exe` рядом.

## Как это работает

Заряд читается обычным HID feature report на 90 байт — тем же, что использует Synapse
(команды `0x07/0x80` — уровень, `0x07/0x84` — зарядка). Протокол описан в открытом проекте
[OpenRazer](https://github.com/openrazer/openrazer). Всё общение с мышью — через `hid.dll`
и `setupapi.dll` по ctypes, без драйверов и сторонних HID-библиотек.
